# Jelly Landscapes — 항구 · 산 · 초원

항구·산·초원을 전환해서 둘러보는 실시간 3D 미니어처입니다. 별도의 이미지 배경이나 외부 3D 모델 없이 Three.js geometry로 풍경을 구성합니다.

**[공개 사이트 열기](https://bishop33.github.io/harbor-jelly/)**

## 느린 하루 — 기차와 숲, 그리고 바다

**[새 여정 열기](https://bishop33.github.io/harbor-jelly/slow-days.html)**

도시를 떠나 내 속도로 하루를 걷는 3장짜리 3D 이야기입니다. 3장에 각각 4개의 짧은 본문이 있으며, 19초마다 다음 문장으로 이어집니다. 점을 눌러 문장을 바꾸거나 ‘천천히 머무르기’로 본문 진행을 멈출 수 있습니다. 장면 전환은 사용자가 선택합니다.

1. **기차에 기대어**: 창밖이 들판 → 숲 → 바다로 변합니다. 창틀, 나무 탁자, 김이 오르는 찻잔, 차표와 창밖 전봇대의 parallax를 표현합니다.
2. **숲의 속도로**: 걸어서 꽃·새·토끼와 다람쥐·나비를 관찰합니다. 가까이 보는 버튼으로 시선이 부드럽게 이동합니다.
3. **발자국을 돌아보며**: 얕은 물결이 드나드는 해변을 걷습니다. 실제 이동 거리마다 좌우 발자국이 남고, 물이 닿으면 서서히 옅어집니다. ‘뒤돌아보기’로 지나온 흔적을 바라봅니다.

직접 드래그해서 둘러보고 W A S D / 방향키 또는 휴대폰의 화살표 버튼으로 걸을 수 있습니다. 자동 산책, 풍경만 보기와 자연음 크기 조절을 제공합니다. 소리는 ‘자연음과 함께 떠나기’ 또는 소리 버튼을 누른 뒤 재생합니다. 음악은 포함하지 않습니다.

새·파도는 CC0 자연 녹음입니다. 바람과 기차 움직임은 filtered noise로 합성합니다. 출처와 변환 내역: `dist/assets/audio/CREDITS.md`. 파일은 로컬에서 제공하며 외부 오디오 CDN에 의존하지 않습니다.

코드: `dist/slow-days.html`, `journey.css`, `journey.js`, `journey-worlds.js`, `journey-math.js`, `journey-audio.js`. 숲의 기본 geometry는 기존 `forest-world.js`를 재사용합니다. 낮은 사양을 위해 이 여정의 숲 범위를 줄이고, 정적 소품은 material별로 합칩니다. 비활성 탭의 렌더링은 쉬고 자연음은 계속 재생합니다.

새 테스트 2개는 실제 보행 때만 남는 좌우 발자국, 휴식·장면 점프 시 흔적을 만들지 않는 동작, 파도가 닿는 발자국만 빨리 지워지는 동작을 확인합니다. 전체 테스트는 11개입니다. 브라우저에서 장면 전환·기차 풍경 변화·숲의 관찰 시점·자연음 로딩·해변의 발자국 생성과 뒤돌아보기, 390×844 화면의 직접 걷기를 확인했습니다. 실제 휴대폰 기기 검증은 별도입니다.

## Afterlight — 숲길 체험

**[숲길 샘플 열기](https://bishop33.github.io/harbor-jelly/forest.html)**

사람 눈높이의 perspective camera로 직접 걷는 별도 3D 체험입니다. 그림 배경 대신 나무·지형·강·나무다리·전망대가 실제 geometry로 존재합니다.

- 화면 드래그로 둘러보기, W A S D / 방향키로 걷기
- 휴대폰의 화살표 버튼을 누르고 걷기
- 자동 산책은 숲길 → 나무다리 → 높은 전망대로 이어지며 직접 움직이면 멈춤
- 장소 버튼은 화면을 부드럽게 어둡게 했다가 새로운 장소를 보여줌
- 일몰·새벽·푸른 밤의 조명, sky shader, 안개와 떠다니는 먼지
- 소리를 켜면 Web Audio로 합성한 바람·물소리 재생 (기본 끔)
- 화면을 가리는 UI를 접는 ‘풍경만 보기’

나무껍질과 풀잎은 procedural shader로 표현합니다. 숲은 merged geometry와 instancing으로 렌더링합니다. 이동 시 나무·바위 충돌을 피하고, 강은 다리로 건너며, 전망대의 계단을 올라갑니다. 사진 같은 모델·텍스처를 사용한 게임의 완성도와는 차이가 있는 브라우저용 stylized prototype입니다.

코드: `dist/forest.html`, `forest.css`, `forest.js`, `forest-world.js`, `forest-math.js`. 테스트: `tests/forest.test.mjs`.

## 새 풍경

상단의 **항구 · 산 · 초원**으로 이동합니다. 각 풍경은 독립된 URL로 공유할 수 있습니다.

- **[Mountain Jelly](https://bishop33.github.io/harbor-jelly/mountain.html)**: 소나무 숲, 눈 덮인 산봉우리, 산장·돌다리·호수·카누·사슴과 두 케이블카. 탑승 버튼은 움직이는 케이블카를 따라 카메라를 전환합니다. 눈 내리기와 바람, 아침·한낮·노을을 조절합니다.
- **[Meadow Jelly](https://bishop33.github.io/harbor-jelly/meadow.html)**: 굽이치는 강, 나무다리, 농장과 풍차, 양 10마리·나비·열기구와 들꽃. 열기구를 따라가는 시점, 들꽃 펼치기·접기, 바람과 시간을 조절합니다.

두 풍경 모두 드래그로 회전, 스크롤·pinch로 확대합니다. 호수나 강을 짧게 누르면 파문이 생깁니다. 산장·호수·산봉우리와 풍차·강·양 떼에 가까이 가는 시점 버튼을 제공합니다. 휴대폰의 조작 패널은 접을 수 있습니다.

## 항구 둘러보기

- 두 gantry crane, 골이 있는 컨테이너, 하역장 레일과 방충용 타이어
- 언덕의 파스텔 집, 창틀·굴뚝·지붕·가로등, 교회와 어시장
- 나무 부두와 작은 어선, 예인선과 화물선, 방파제와 회전하는 등대 불빛
- 투명한 수면과 단면, 수중 빛무늬, 물고기 52마리와 해파리, 해초·불가사리·닻

배는 **하역 → 선적 → 크레인 들어 올리기 → 예인선 접근 → 출항 → 항해 → 귀항 → 접안**을 반복합니다. 일찍 출항을 요청하면 진행 중인 상자를 마저 옮깁니다. 바다에서는 귀항을 요청할 수 있습니다.

## 직접 조작

- 수면을 드래그하면 파문이 퍼집니다. 블록 옆면을 드래그하면 잠깐 기울어집니다.
- 주황색 구명환을 잡아서 던질 수 있습니다.
- 빈 공간 또는 오른쪽 드래그로 회전하고 스크롤로 확대합니다.
- 휴대폰에서는 드래그로 회전하고 두 손가락으로 확대합니다. 수면을 짧게 터치하면 파문이 생깁니다.
- 먹이를 주면 알갱이가 떨어지고 물고기들이 부두에 모입니다. 경적을 울리면 갈매기가 흩어집니다.
- 바다 색, 탱글함, 물결 감쇠와 수위를 바꿀 수 있습니다.
- 전체·하역장·수중·등대 버튼은 카메라를 부드럽게 이동시킵니다.
- 소리는 기본적으로 꺼져 있습니다. 켜면 합성한 뱃고동이 재생됩니다.

## 로컬 실행

```sh
python3 -m http.server 8766 --directory dist
```

브라우저에서 <http://localhost:8766>을 엽니다. ES modules를 사용하므로 HTTP 서버가 필요합니다. build나 외부 CDN 연결은 필요하지 않습니다.

```sh
npm test
node --check dist/harbor.js
node --check dist/harbor-world.js
```

기존 테스트 9개는 숲길의 전체 도보 경로·다리·전망대 접근과 강·나무 충돌 방지, 케이블카의 지형 clearance, 양이 강을 피하는 경로, 두 풍경의 geometry·날씨 상태와 항구의 전체 운영 주기, 조기 출항·귀항, 물결의 안정성과 감쇠, 배가 부두·방파제를 피하는 항로를 확인합니다. 브라우저에서는 데스크톱과 390×844 화면의 렌더링·조작 패널·수위·색·출항·귀항을 확인했습니다. 새 산·초원 풍경은 데스크톱과 390×844 화면에서 전환·탑승·시간·눈·들꽃·패널 조작을 확인했습니다. 실제 휴대폰의 pinch 동작은 별도 검증이 필요합니다.

## 소스

- `dist/mountain.html`, `dist/meadow.html`: 풍경별 진입 화면
- `dist/nature-world.js`: 지형, 나무·건물·동물·날씨·탈것
- `dist/nature.js`: 카메라, 조명, UI와 애니메이션
- `dist/landscape-math.js`: 지형과 탈것·동물 경로
- `dist/landscapes.css`: 공통 풍경 전환 메뉴와 UI
- `tests/landscape.test.mjs`: 지형·경로·geometry 검증

- `dist/harbor-world.js`: 건물·배·크레인·생물과 수중 소품
- `dist/harbor-sim.js`: 물결 계산과 항구 운영 상태
- `dist/harbor-motion.js`: 화물선 항로
- `dist/harbor.js`: 렌더링, 애니메이션, 카메라와 입력
- `dist/harbor.css`, `dist/index.html`: 반응형 조작 화면
- `tests/harbor.test.mjs`: 핵심 동작 테스트
- `dist/vendor/`: Three.js 0.180.0과 OrbitControls, MIT license
- `dist/assets/`: local fonts와 Phosphor icons, 각 license 포함

물은 WebGL render target을 사용한 screen-space 굴절과 단면 transmission으로 표현합니다. 물결과 부력은 시각 효과용 근사 모델입니다. 배와 크레인은 미리 정한 항로·상태에 따라 움직입니다.

소설·게임 방향의 작업은 `codex/lyrical-novel` branch에 별도로 보존했습니다. 이전 소설 모듈도 남아 있지만 현재 entrypoint에서는 로드하지 않습니다.

Afterlight는 390×844와 desktop 화면에서 걷기 버튼, 시선 드래그, 장소 이동, 시간대 전환과 자동 산책을 검증했습니다.

## 배포

`main`에 push하면 GitHub Actions가 문법·동작 테스트를 실행한 뒤 `dist`를 GitHub Pages에 배포합니다. 로그인이나 API key 없이 열 수 있습니다.
